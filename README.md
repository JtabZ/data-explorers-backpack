# Data Explorers Backpack: public demo

**Try it:** https://jtabz.github.io/data-explorers-backpack/

A click-through version of the Data Explorers Backpack, a companion app for Tableau Studio. It turns a curiosity ("I'm curious about … because …") into a guided exploration with three tools:

- **Compass** finds data sources that fit the question, shows them as Trail Cards, and writes a brief with starter questions, a first move and watch-outs.
- **Field Guide** explains what fields mean and how to use them, without giving away the answer.
- **Trail Journal** records what you build, dead ends included, and turns it into a story at the end.

## What's different in this version

This copy runs entirely in your browser and isn't connected to anything.

| In the full app | In this demo |
|---|---|
| Compass searches your Tableau Cloud site and Data 360 semantic models | Compass searches a few packaged sample data sources |
| Launch opens worksheets in Tableau Studio, and the Journal watches them | Studio is simulated |
| On the Trail embeds your own workbook in Web Edit | On the Trail embeds a Tableau Public dashboard |

Your expeditions are saved in your browser only. **Reset demo** in the banner clears them.

## A 3-minute walkthrough

1. On Base Camp, click **Begin New Expedition**.
2. Enter a curiosity, e.g. *regional profit margin*, because *Central sales look strong but profit doesn't*.
3. Pick a Trail Card, pack it, and read the brief.
4. Launch, then explore the dashboard on **On the Trail**: capture a snapshot and flag a dead end.
5. Click **Make Camp** to write the story and export it.

A finished sample expedition, *Profit Erosion*, is on Base Camp if you'd rather see the end first.
